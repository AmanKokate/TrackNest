🚀 TrackNest – A Django CRM App! 🎉


TrackNest is a Customer Relationship Management (CRM) application built with Django, HTML, CSS, Bootstrap, and JavaScript. It provides a seamless way to manage customer data efficiently.

✅ Features
🔹 Full CRUD operations for easy data management
🔹 User-friendly UI with Bootstrap styling
🔹 Deployed on Koyeb for smooth hosting

🚀 Getting Started

1. Clone the repository

git clone https://github.com/AmanKokate/TrackNest.git
cd TrackNest

2. Install dependencies
pip install -r requirements.txt

3. Run the application
python manage.py runserver

4. Access in browser
http://127.0.0.1:8000/
